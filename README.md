# 🍞 面包手记 (bread-notes)

一个给家庭烘焙爱好者用的面包配方 & 烘焙记录小工具。纯静态网页（PWA），无需后端、无需构建，可免费部署在 GitHub Pages，手机上可“添加到主屏幕”离线使用。

## 功能

- **配方管理**：新建 / 编辑 / 复制 / 删除配方；勾选面粉后自动计算**烘焙百分比**和**含水量（水合率）**（牛奶、鸡蛋、鲁邦种等按含水比例折算）。
- **按需缩放**：输入目标面团总重或目标个数，一键换算所有用量。
- **单项费用**：「我的 → 原料价格库」记录每种原料的购买价和规格（如 ¥12 / 500g），自动算出每克成本；所有配方共享，显示配方总成本和每个成本。
- **费用统计**：按月 / 按配方 / 按原料汇总花费，带柱状图与占比表。
- **烘焙记录（持续跟进）**：每次烘焙记录日期、评分、烤温、时间、发酵情况、心得，可拍照/上传多张照片（自动压缩，存于本机 IndexedDB），时间线展示。
- **分享**：生成精美分享卡片（照片 + 配方名 + 比例 + 成本），可保存图片或调用系统分享。
  - 分享到**微信朋友圈**：网页无法直接发朋友圈，请保存图片后在微信朋友圈从相册选择发布（微信内置浏览器中长按图片即可保存）。
- **获取面包做法**：
  - 内置 10 个经典配方：吐司、欧包、贝果、法棍、可颂、餐包、恰巴塔、布里欧修、全麦面包、肉桂卷。
  - 一键跳转**下厨房 / 小红书**搜索。
  - **导入**：把小红书、下厨房上复制的用料文字（如 `高筋面粉 250g`、`牛奶：130克`、`鸡蛋 1个`）粘贴进来，自动识别成配方，并保留来源链接。
  - 说明：由于浏览器跨域限制（CORS）和平台服务条款，纯静态网页**无法直接抓取**小红书 / 下厨房的内容，因此采用“跳转搜索 + 复制粘贴导入”的方式。
- **主题色**：8 种预设 + 自定义颜色；支持浅色 / 深色 / 跟随系统。
- **数据备份**：所有数据只存在本机浏览器；可导出 / 导入 JSON 备份（包含照片）。
- **离线可用**：Service Worker 缓存，可安装到手机主屏幕。

## 使用

- 在线：部署后访问 `https://<你的用户名>.github.io/bread-notes/`
- 本地：`python3 -m http.server 8000` 后打开 http://localhost:8000

## 部署到 GitHub Pages（免费）

1. 把本仓库推送到 GitHub（仓库名 `bread-notes`）。
2. 仓库 Settings → Pages → Source 选 “Deploy from a branch”，Branch 选 `main`，目录 `/ (root)`，保存。
3. 一两分钟后即可通过上面的地址访问。无需 GitHub Actions、无需构建。

## 目录结构

```
index.html        入口页面
css/style.css     样式（CSS 变量主题、深色模式）
js/library.js     内置经典配方 + 默认原料价格
js/store.js       数据层（localStorage + IndexedDB 照片、成本/比例计算、文本解析）
js/app.js         页面路由与界面逻辑、分享卡片、统计图表
sw.js             Service Worker（离线缓存）
manifest.json     PWA 清单
icons/            应用图标
tests/e2e.js      Playwright 端到端测试
```

## 测试

```bash
python3 -m http.server 8765 &
npm i playwright && npx playwright install chromium
node tests/e2e.js
```

## 注意

- 数据保存在当前浏览器中，清除浏览器数据或换设备会丢失，请定期导出备份。
- 默认原料价格仅供参考，请按自己的购买价修改。
